# Daniel-PDF-Gal – אפליקציית PDF אישית לאנדרואיד

גרסה 0.1 (MVP). אין בה פרסומות, וגם אין לה הרשאת אינטרנט בכלל.

## מה יש בגרסה הזו
- פתיחת PDF מהמכשיר, וגם דרך "פתח באמצעות" מאפליקציות אחרות
- ציור בעט ובמרקר (עם תמיכה בסטיילוס), מחק, בחירת צבע ועובי, ביטול וחזרה
- הוספת טקסט בעברית מיושר לימין, ב־17 גופנים עבריים חופשיים (כמה שורות, צבע וגודל לבחירה)
- סריקת מסמכים במצלמה (ML Kit): חיתוך אוטומטי ושמירה כ־PDF
- מיזוג כמה קבצי PDF לקובץ אחד
- שמירה כקובץ חדש. הגופנים מוטמעים בקובץ, כך שהוא ייראה אותו דבר בכל מחשב

## איך בונים ומתקינים
1. מתקינים את Android Studio (חינמי): https://developer.android.com/studio
2. פותחים: File → Open → בוחרים את התיקייה `HebPDF`
3. מחכים שהסנכרון (Gradle Sync) יסתיים. בפעם הראשונה זה לוקח כמה דקות
4. בטלפון מפעילים "אפשרויות מפתח" (נוגעים 7 פעמים ב"מספר Build" בהגדרות → אודות הטלפון), ואז מפעילים "ניפוי באגים ב־USB"
5. מחברים את הטלפון בכבל ולוחצים על ▶ Run

אפשרות בלי כבל: Build → Build APK(s). אחר כך מעבירים את הקובץ `app/build/outputs/apk/debug/app-debug.apk` לטלפון ומתקינים אותו.

## הוספת גופנים
מעתיקים קבצי TTF או OTF לתיקייה `app/src/main/assets/fonts/` ובונים מחדש.

## מגבלות ידועות (לשלבים הבאים)
- זום: צביטה בשתי אצבעות, הזזה בשתי אצבעות או בכלי "הזזה", הקשה כפולה בכלי הזזה לזום מהיר
- עמודים שמסובבים ב־PDF עצמו עלולים להיות מוצגים במיקום לא נכון
- ניקוד: מוצג נכון על המסך. בקובץ השמור המיקום שלו מקורב
- עדיין אין: עריכה של טקסט קיים, OCR, חתימה שמורה, סידור עמודים, סיסמה
